# YummYummy

YummYummy is a shared household food-planning application built around four core concepts: inventory, shopping demand, recipes, and meal intent.

The MVP will use Laravel, Vue, Inertia, PostgreSQL, Redis, and Laravel Sail. Recipe recommendations will be deterministic first, with natural-language AI added later as an interface over validated application services.

## Status

The repository is being bootstrapped. Product development is tracked through GitHub milestones and atomic issues.
